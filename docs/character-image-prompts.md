# 角色立绘生成提示词指南

本文档记录 Fantasy Gacha Lab 当前角色立绘的生成规范、主题分组和可复用提示词。后续新增角色时，优先复用这里的模板和主题目录，保证新资源与现有卡牌 UI 风格一致。

## 资源规范

- **画幅**：竖版角色立绘，适合裁切为 3:4 卡牌。
- **风格**：精致二次元幻想抽卡游戏插画。
- **格式**：PNG 图片。
- **画面要求**：无 UI、无文字、无 Logo、无水印。
- **构图**：半身到四分之三身，角色居中，四周保留适当裁切空间。
- **背景**：与角色主题分组一致的幻想背景。
- **稀有度方向**：
  - **SSR**：宏大、神性、高细节、强光效、顶级卡面表现。
  - **SR**：精致、有辨识度，华丽程度略低于 SSR。
  - **R**：干净、易读，服装和特效更朴素，偏见习者或普通冒险者。

## 主题分组目录

图片统一存放在：

```text
public/characters/<theme>/<filename>.png
```

| 主题目录 | 中文名 | 适用角色方向 |
|---|---|---|
| `starlight-order` | 星辉圣序 | 光明、圣洁、星空、天空、教堂、誓约 |
| `nightfall-court` | 夜幕王庭 | 暗影、月夜、深渊、王庭、刺客 |
| `crimson-coven` | 绯焰秘会 | 火焰、绯红魔法、魔法学院、魔女 |
| `verdant-path` | 森绿旅途 | 森林、自然、草药、流浪者、治愈 |
| `storm-vanguard` | 雷鸣先锋 | 雷电、疾速、剑士、决斗者 |
